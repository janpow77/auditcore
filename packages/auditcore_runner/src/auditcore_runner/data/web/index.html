auditcore-runner

Die Oberfläche wird geladen … Ohne JavaScript bleiben die CLI (auditcore-runner profil …) und die JSON-API:

  • /api/status – Rechner, Klassen, Soll, Runner, Image, Netzsperre
  • /api/profil – Profil, Hardware, Validierung
  • /api/werkzeuge – Werkzeuge und Prüfprofile
  • /metrics – Prometheus
